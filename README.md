# Restaurant AI

### Интеллектуальная система управления ресторанными заказами

Веб-приложение для автоматизации обработки заказов, контроля загрузки кухни и бара, анализа времени приготовления и поддержки принятия решений персоналом.

---

## О проекте

**Restaurant AI** объединяет управление заказами, аналитику, машинное обучение и интеллектуальные рекомендации в одной системе.

Официант создаёт заказ, после чего система автоматически распределяет его позиции между рабочими станциями — **кухней** и **баром**.

Во время обработки заказа система отслеживает его состояние, рассчитывает приоритет, контролирует загрузку рабочих станций и прогнозирует время приготовления.

---

## Возможности

### Управление заказами

- Создание новых заказов
- Добавление нескольких позиций
- Указание номера стола
- Изменение статуса заказа
- Контроль времени ожидания
- Завершение заказа

### Распределение по рабочим станциям

Система автоматически разделяет позиции заказа между кухней и баром.

~~~text
                    ЗАКАЗ
                       │
             ┌─────────┴─────────┐
             │                   │
            БАР                КУХНЯ
             │                   │
        Напитки             Блюда и десерты
~~~

Для каждой рабочей станции формируется отдельная очередь заказов.

### Система приоритетов

Приоритет заказа рассчитывается с учётом:

- времени ожидания;
- количества позиций;
- планового времени приготовления.

Система определяет причину повышенного приоритета:

- длительное ожидание;
- большое количество позиций;
- длительное приготовление.

### Контроль загрузки

Dashboard отображает:

- количество активных заказов;
- загрузку кухни;
- загрузку бара;
- заказы с длительным ожиданием;
- текущую ситуацию в ресторане.

### Аналитика

Система предоставляет:

- среднее время приготовления;
- анализ популярных позиций;
- статистику заказов;
- данные для обучения ML-модели;
- текущие показатели ресторана.

---

## Machine Learning

Для прогнозирования времени приготовления используется модель **Linear Regression** из библиотеки **Scikit-learn**.

### Входные параметры модели

- общее количество позиций;
- количество позиций кухни;
- количество позиций бара;
- плановое время приготовления.

~~~text
Количество позиций
        +
Позиции кухни
        +
Позиции бара
        +
Плановое время
        │
        ▼
   ML-модель
        │
        ▼
Прогноз времени приготовления
~~~

Модель обучается на завершённых заказах, для которых известно фактическое время приготовления.

---

## Интеллектуальные рекомендации

Система анализирует текущую ситуацию в ресторане и формирует рекомендации для персонала.

При анализе учитываются:

- активные заказы;
- загрузка кухни;
- загрузка бара;
- время ожидания;
- приоритеты заказов;
- результаты ML-прогнозирования.

### Пример

~~~text
Ситуация:
Кухня имеет высокую загрузку.

Проблема:
Есть заказ с длительным ожиданием.

Рекомендация:
Обработать заказ с высоким приоритетом.
~~~

Таким образом, система помогает персоналу определить, на какие заказы необходимо обратить внимание в текущий момент.

      │
      ▼
┌───────────┐

      │
      ▼

### Backend

Backend реализован на:

- Python
- FastAPI
- SQLAlchemy

Отвечает за:

- REST API;
- работу с заказами;
- бизнес-логику;
- расчёт приоритетов;
- аналитику;
- контроль загрузки;
- ML-прогнозирование;
- интеллектуальные рекомендации.

### Database

Для хранения данных используется **PostgreSQL**.

Основные таблицы:

- `orders`
- `order_items`
- `menu_items`

### Frontend

Frontend реализован с использованием:

- HTML
- CSS
- JavaScript

Основной интерфейс системы представлен Dashboard.
