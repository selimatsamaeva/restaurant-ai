# Restaurant AI

Информационная система управления заказами
в предприятии общественного питания.

## Цель проекта

Разработка системы, которая объединяет работу
официанта, кухни и бара, помогает отслеживать
заказы и анализировать загрузку сотрудников.

## Основные возможности

- создание заказов официантом;
- передача заказов на кухню и бар;
- отслеживание статуса заказа;
- контроль загрузки;
- прогноз времени готовности;
- выявление возможных задержек;
- рекомендации для сотрудников на основе анализа данных.
