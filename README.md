# Restaurant AI

Интеллектуальная информационная система для управления заказами
и контроля загрузки рабочих станций ресторана.

## О проекте

Restaurant AI — веб-система для автоматизации обработки
ресторанных заказов.

Система позволяет официанту создавать заказ, автоматически
распределять его позиции между кухней и баром, отслеживать
статус приготовления и анализировать загрузку рабочих станций.

Дополнительно реализованы ML-прогнозирование времени приготовления
и модуль интеллектуальных рекомендаций.

## Основные возможности

- создание и просмотр заказов;
- изменение статуса заказа;
- автоматическое распределение позиций по рабочим станциям;
- отдельные очереди кухни и бара;
- расчёт приоритета заказа;
- определение причины высокого приоритета;
- контроль загрузки кухни;
- контроль загрузки бара;
- расчёт среднего времени приготовления;
- анализ популярных позиций;
- ML-прогноз времени приготовления;
- интеллектуальные рекомендации;
- Dashboard с текущим состоянием ресторана;
- автоматическое обновление аналитической информации.

## Архитектура

Проект состоит из трёх основных частей:

### Backend

Реализован на Python и FastAPI.

Backend отвечает за:

- REST API;
- работу с заказами;
- бизнес-логику;
- расчёт приоритетов;
- аналитику;
- загрузку рабочих станций;
- ML-прогнозирование;
- интеллектуальные рекомендации.

### Database

Для хранения данных используется PostgreSQL.

Основные сущности:

- `orders`;
- `order_items`;
- `menu_items`.

Связь между заказом и позициями реализована через
таблицу `order_items`.

### Frontend

Frontend реализован с использованием:

- HTML;
- CSS;
- JavaScript.

Основной интерфейс системы представлен Dashboard,
на котором отображаются текущие показатели ресторана.

## ML-модуль

В системе используется модель машинного обучения
`LinearRegression`.

Для прогнозирования используются следующие признаки:

- количество позиций в заказе;
- количество позиций кухни;
- количество позиций бара;
- плановое время приготовления.

Модель обучается на завершённых тестовых заказах,
для которых известно фактическое время приготовления.

Результатом работы модели является прогноз времени
приготовления нового заказа.

## Интеллектуальные рекомендации

Интеллектуальный модуль анализирует текущую ситуацию
в ресторане.

Для формирования рекомендаций используются:

- количество активных заказов;
- загрузка кухни;
- загрузка бара;
- длительность ожидания;
- приоритет заказов;
- результаты ML-прогнозирования.

На основе этих данных система может определить
проблемные ситуации и сформировать рекомендацию
для персонала.
