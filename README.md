Restaurant AI
Интеллектуальная информационная система для управления ресторанными заказами, контроля загрузки рабочих станций и поддержки принятия решений персоналом.

О проекте
Restaurant AI — веб-приложение для автоматизации обработки заказов в ресторане.

Система позволяет официанту создавать заказ, автоматически распределять его позиции между кухней и баром, отслеживать этапы приготовления, рассчитывать приоритеты и контролировать текущую загрузку рабочих станций.

В проект также входят аналитический модуль, ML-прогнозирование времени приготовления и модуль интеллектуальных рекомендаций.

Основные возможности
создание заказов;

просмотр активных и завершённых заказов;

изменение статуса заказа;

автоматическое распределение позиций между кухней и баром;

отдельные очереди рабочих станций;

расчёт приоритета заказа;

определение причины высокого приоритета;

контроль времени ожидания;

расчёт загрузки кухни;

расчёт загрузки бара;

расчёт среднего времени приготовления;

анализ популярных позиций;

формирование обучающей выборки;

ML-прогнозирование времени приготовления;

интеллектуальные рекомендации;

отображение текущей ситуации в ресторане;

автоматическое обновление Dashboard.

Логика работы системы
Основной сценарий обработки заказа:

Создание заказа
       ↓
     Новый
       ↓
    Принят
       ↓
   Готовится
       ↓
     Готов
       ↓
     Выдан
При создании заказа система анализирует входящие позиции и автоматически определяет рабочую станцию для каждой из них.

Например:

Заказ
 ├── Капучино ×2 → Бар
 ├── Паста ×1     → Кухня
 └── Чизкейк ×1   → Кухня
Это позволяет разделить работу между станциями и формировать отдельные очереди.

Приоритеты заказов
Приоритет рассчитывается с учётом нескольких факторов:

времени ожидания;

количества позиций;

планового времени приготовления.

Таким образом, система может выделять заказы, которые требуют более быстрого внимания.

Также определяется причина высокого приоритета:

длительное ожидание;

большое количество позиций;

длительное приготовление.

Контроль загрузки
Система рассчитывает текущую нагрузку кухни и бара на основе активных заказов и планового времени приготовления.

На Dashboard отображаются:

количество активных заказов;

загрузка кухни;

загрузка бара;

количество заказов с длительным ожиданием;

текущая ситуация в ресторане.

ML-модуль
Для прогнозирования времени приготовления используется модель машинного обучения LinearRegression из библиотеки Scikit-learn.

Для обучения используются следующие признаки:

общее количество позиций;

количество позиций кухни;

количество позиций бара;

плановое время приготовления.

Модель обучается на завершённых заказах, для которых известно фактическое время выполнения.

После обучения система может получить прогноз времени приготовления нового заказа.

Интеллектуальные рекомендации
В проекте реализован модуль интеллектуальных рекомендаций, который анализирует текущую ситуацию в ресторане.

Для формирования рекомендаций используются:

активные заказы;

загрузка кухни;

загрузка бара;

время ожидания;

приоритеты;

результаты ML-прогнозирования.

На основании этих данных система формирует текстовые рекомендации для персонала.

Пример:

Ситуация:
Кухня имеет высокую загрузку.

Проблема:
Заказ ожидает длительное время.

Рекомендация:
Обработать заказ с высоким приоритетом в первую очередь.
Архитектура
Проект состоит из трёх основных частей:

Backend
Backend реализован на Python с использованием FastAPI.

Отвечает за:

REST API;

работу с заказами;

бизнес-логику;

расчёт приоритетов;

аналитику;

контроль загрузки;

ML-прогнозирование;

интеллектуальные рекомендации.

Database
Для хранения данных используется PostgreSQL.

Основные сущности:

orders;

order_items;

menu_items.

Таблица order_items связывает заказы с позициями меню.

Frontend
Frontend реализован с использованием:

HTML;

CSS;

JavaScript.

Основной интерфейс системы представлен Dashboard.

Назначение проекта
Система предназначена для автоматизации обработки ресторанных заказов и предоставления персоналу информации о текущей загрузке рабочих станций.

Проект объединяет управление заказами, аналитические инструменты и методы машинного обучения в единой информационной системе.
